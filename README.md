# OpenDrop

An unofficial, open-source Android app for controlling Moondrop audio devices.

**Status:** planning / protocol research. First target: the original
**Moondrop Space Travel** earbuds.

Planned features: ANC mode, EQ presets, battery levels, game mode, touch
remapping and lock, codec switching, and a phone-side parametric EQ.
See [docs/ROADMAP.md](docs/ROADMAP.md) for the full plan.

> OpenDrop is not affiliated with or endorsed by Moondrop.
