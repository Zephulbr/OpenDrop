# Moondrop 2.26.2c Findings: Feature Tiers and Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the 2.26.2c protocol findings into three explicit tiers: a small capture-safe release now, a developer-options track for App-only commands, and a documented defer/avoid list for anything irreversible or still unknown.

**Architecture:** Tier 1 adds only local decoding, standard USB reads and honest reporting, so no new vendor command reaches a device by default. Tier 2 adds a hidden, opt-in protocol console with read-first probes and a small set of reversible writes; it never includes flash, OTA, reset, identity or coefficient writes. Tier 3 is a decision record, not code.

**Tech Stack:** Kotlin 2.0 (JVM + Android), JUnit 4, Compose, Python 3 stdlib tools, no new dependencies.

**Spec:**
- `docs/protocol/usb-dac.md` (five USB families, App only)
- `docs/protocol/moondrop-gaia-features.md` (GAIA 0–35 command map)
- `docs/protocol/space-travel.md` (SPP, session sequence, user EQ)
- `docs/devices.md` (model catalogue, unknowns)
- `docs/ROADMAP.md` (principles and M2/M5 status)
- `docs/protocol/captures/2026-10-07-probe-user-eq.txt` (correction note)

## Global Constraints

- **Evidence gate:** by default, the app sends only commands backed by a capture (`Wire`) or standard USB requests that change nothing (descriptors, strings). `App`-only vendor commands are allowed only in the Tier 2 console, after the user enables it and confirms the risk.
- **Never in any tier:** firmware update/OTA, flash/NVM save, factory reset, serial/MAC writes, audio-file upload/format/delete. These are out of scope, not "later".
- **Device-driven:** never offer a probe for a GAIA feature the connected device did not advertise. USB probes are offered only for the identified family.
- **Testable without hardware:** all frame builders/parsers are pure Kotlin (or Python) and tested against literal bytes. Android transport classes have no test harness, so they are verified by build + lint + a hardware pass.
- **Commands:** `.\gradlew.bat :core:protocol:test :core:dsp:test`, `python -m unittest discover -s tools`, `.\gradlew.bat :app:assembleDebug :app:lintDebug` on Windows; `./gradlew …` elsewhere.
- **No new dependencies, permissions, network access or tracking.** F-Droid is a goal.
- New `strings.xml` keys go into all nine translated `values-*/strings.xml` files with placeholders intact.
- Commit style `Area: lowercase summary`. Do not commit or push unless the human asks.
- Privacy: no Bluetooth MAC, serial number or CAPE/device-unique string in a shared report by default; the console has its own explicit "show serial numbers" switch.
- Do not upgrade an `App`/`Inferred` tag in the docs without a capture.

## Review Focus

The five input classes most likely to bite a user, and where each is pinned:

1. **Short or malformed user-EQ replies** (2-byte header only, payload not a multiple of 7, `end` disagreeing with the band count) → `UserEqTest` in Task 3 and the Python malformed test in Task 1.
2. **Unknown or renumbered GAIA features** (feature 28 absent, OEM ids outside 0–35, error frames) → `GaiaDescribeTest` fallback in Task 2.
3. **USB devices with no CAPE string, no HID descriptor or a descriptor the naive parser would misread** → `UsbHidTest` and `UsbIdentityTest` in Task 4.
4. **A known model whose USB product string does not match the catalogue** (Dawn Pro 2 variants, localized strings) → VID/PID + CAPE fallback in Task 4.
5. **A dev-console probe sent to a device that does not advertise the feature, or a write whose read-back never arrives** → feature gating and read-back rules in Tier 2; no default-path code depends on them.

| SPP UUIDs and session sequence | **App** + **Wire** on ST1 | Nothing to change: `RfcommLink` already uses the SPP UUID with a channel-1 fallback | Other models' channels/UUIDs are untested |

### Findings that need no code

- **SPP UUID selection.** `RfcommLink` already opens `createRfcommSocketToServiceRecord(00001101-…)` and falls back to channel 1. The vendor UUID `00001107-D102-11E1-9B23-00025B00A5A5` can be added later as a second fallback; it is not worth untested connection code in Tier 1.
- **Core `0x13`–`0x16`.** They are Basic commands 19–22 (language, left serial, right serial, TWS status). The ST1 does not reply, so there is no feature to ship. Privacy also argues against surfacing serials by default.
- **Feature 28.** It does not exist. No gap to fill.

## 1. The tier rule

| Tier | Gate | Ships where | Allowed | Failure mode |
|---|---|---|---|---|
| **1 — ship now** | `Wire`, or no bytes leave the phone, or a standard read-only USB request | Default app path | Local decoding, descriptor/string reads, reports, docs/tools | A descriptor read stalls or returns null; caught and reported |
| **2 — dev options only** | `App` evidence, no capture | Hidden console, off by default, explicit opt-in | Read-first probes; reversible writes with read-back | Device ignores the command or the setting does not stick; nothing persistent is written |
| **3 — avoid / later** | `App` + irreversible, unknown math, identity, or no evidence | Nowhere | A written decision, not an implementation | Bricked device, lost pairing/identity, hearing risk, or unrecoverable setting |

**Why App-only is not Tier 1:** the repo's rule is "never send a command that wasn't captured first" (`ROADMAP`, guiding principle 2). "Official" status does not change what has been observed; a capture or firmware confirmation does. The Tier 2 console is the one deliberate exception already anticipated by the risk table ("never send unknown commands outside the dev console").

```python
FILTER_NAMES = {
    0: "bypass", 1: "LP1", 2: "HP1", 3: "AP1", 4: "LS1", 5: "HS1", 6: "tilt1",
    7: "LP2", 8: "HP2", 9: "AP2", 10: "LS2", 11: "HS2", 12: "tilt2", 13: "PEQ",
}


def user_eq(p: bytes) -> str:
    if len(p) < 2 or (len(p) - 2) % 7:
        return f"malformed user EQ ({len(p)} bytes)"
    bands = []
    for i in range((len(p) - 2) // 7):
        o = 2 + i * 7
        hz = int.from_bytes(p[o:o + 2], "big")
        q = int.from_bytes(p[o + 2:o + 4], "big") / 4096
        ft = p[o + 4]
        gain = int.from_bytes(p[o + 5:o + 7], "big", signed=True) / 60
        bands.append(f"{hz} Hz, Q {q:.3f}, type {ft} ({FILTER_NAMES.get(ft, '?')}), {gain:+.1f} dB")
    detail = "; ".join(bands) if bands else "none"
    return f"start {p[0]}, end {p[1]}, {len(bands)} bands: {detail}"
```

```kotlin
package org.opendrop.protocol

/** Human-readable GAIA frames for the packet log; names only, no payload guessing. */
object GaiaDescribe {
    /** Serial replies are device-unique; the shared log masks them unless explicitly asked. */
    private val SERIAL_COMMANDS = setOf(0 to 3, 0 to 20, 0 to 21)

    fun line(frame: GaiaFrame, redactSerials: Boolean = true): String {
        if (frame.vendor == Gaia.VENDOR_V2) {
            return "v2 0x%04x %s".format(frame.command, frame.payload.toHex()).trimEnd()
        }
        val payload = if (redactSerials && (frame.feature to frame.cmd) in SERIAL_COMMANDS) {
            "[redacted]"
        } else {
            frame.payload.toHex()
        }
        return "f%d %s cmd 0x%02x [%s] %s".format(
            frame.feature,
            GaiaFeature.key(frame.feature),
            frame.cmd,
            frame.type.name.lowercase(),
            payload,
        ).trimEnd()
    }
}
```

```kotlin
package org.opendrop.protocol

data class UserEqBand(
    val frequencyHz: Int,
    /** Q × 4096 on the wire. */
    val q: Double,
    /** 0 bypass, 1–12 shelf/tilt variants, 13 parametric EQ (2.26.2c enum). */
    val filterType: Int,
    /** dB × 60 on the wire, signed. */
    val gainDb: Double,
)

data class UserEqConfig(val startBand: Int, val endBand: Int, val bands: List<UserEqBand>)

object UserEq {
    fun parse(payload: ByteArray): UserEqConfig? {
        if (payload.size < 2 || (payload.size - 2) % 7 != 0) return null
        val bands = (0 until (payload.size - 2) / 7).map { i ->
            val o = 2 + i * 7
            UserEqBand(
                frequencyHz = payload.u16(o),
                q = payload.u16(o + 2) / 4096.0,
                filterType = payload[o + 4].toInt() and 0xFF,
                gainDb = payload.i16(o + 5) / 60.0,
            )
        }
        return UserEqConfig(payload[0].toInt() and 0xFF, payload[1].toInt() and 0xFF, bands)
    }

    private fun ByteArray.u16(i: Int) = ((this[i].toInt() and 0xFF) shl 8) or (this[i + 1].toInt() and 0xFF)

    private fun ByteArray.i16(i: Int) = u16(i).toShort().toInt()
}
```

```kotlin
object UsbHid {
    /** Report IDs declared by a HID report descriptor (short item 0x85). */
    fun reportIds(descriptor: ByteArray): Set<Int> {
        val ids = linkedSetOf<Int>()
        var i = 0
        while (i < descriptor.size) {
            val prefix = descriptor[i].toInt() and 0xFF
            if (prefix == 0xFE) { // long item: prefix, data size, tag, data
                if (i + 2 >= descriptor.size) break
                i += 3 + (descriptor[i + 1].toInt() and 0xFF)
                continue
            }
            val size = when (prefix and 0x03) { 0 -> 0; 1 -> 1; 2 -> 2; else -> 4 }
            if ((prefix and 0xFC) == 0x84 && size == 1 && i + 1 < descriptor.size) {
                ids += descriptor[i + 1].toInt() and 0xFF
            }
            i += 1 + size
        }
        return ids
    }
}
```

**Console contract:**

- The master switch is off by default and lives at the bottom of Settings → About ("Developer options — experimental protocol access").

- The console lists only probes for features the device advertises (GAIA) or the family identified (USB).

- Every TX/RX is logged through the existing packet log. The console shows the last reply as hex, annotated.

**Probe model.** Reads are fixed frames; writes need a value selector, so they are separate descriptors. Keeping them apart stops the console from sending an arbitrary payload.

```kotlin
data class DevRead(
    val id: String,
    val feature: Int,
    val cmd: Int,
    val payload: ByteArray,
    val label: String,
)

data class DevWrite(
    val id: String,
    val feature: Int,
    val cmd: Int,
    val label: String,
    /** Values the UI may offer; each maps to one encoded payload. */
    val values: List<Int>,
    val encode: (Int) -> ByteArray,
)

object DevProbes {
    val reads: List<DevRead>
    val writes: List<DevWrite>
    /** Reviewed (feature, cmd) pairs; anything else is rejected by [GaiaSession.write]. */
    val allowedWrites: Set<Pair<Int, Int>> = writes.map { it.feature to it.cmd }.toSet()
    fun readsFor(features: Set<Int>) = reads.filter { it.feature in features }
    fun writesFor(features: Set<Int>) = writes.filter { it.feature in features }
}
```

`GaiaDeviceState.features` is a `Map<Int, Int>` (id → version), so callers pass `state.features.keys`.

`GaiaSession` gets:

```kotlin
/** Sends a console read. False unless the feature was advertised. */
fun probe(read: DevRead): Boolean {
    if (!state.featuresKnown || read.feature !in state.features) return false
    transmit(Gaia.encode(read.feature, read.cmd, read.payload))
    return true
}

/** Sends a reviewed reversible write. False unless the feature is advertised and writes are enabled. */
fun write(write: DevWrite, value: Int, allowWrite: Boolean): Boolean {
    if (!allowWrite) return false
    if (value !in write.values) return false
    if (!state.featuresKnown || write.feature !in state.features) return false
    if ((write.feature to write.cmd) !in DevProbes.allowedWrites) return false
    transmit(Gaia.encode(write.feature, write.cmd, write.encode(value)))
    return true
}
```

```kotlin
object SpvFrame {
    fun get(cmd: Int): ByteArray = frame(0x80, cmd, ByteArray(0))
    fun set(cmd: Int, payload: ByteArray): ByteArray = frame(0x01, cmd, payload)
    private fun frame(type: Int, cmd: Int, payload: ByteArray): ByteArray {
        require(payload.size <= 60) { "SPV payload max 60 bytes" }
        return ByteArray(64).also {
            it[0] = 0x4B; it[1] = type.toByte(); it[2] = cmd.toByte()
            it[3] = payload.size.toByte(); payload.copyInto(it, 4)
        }
    }
}
```

Test literal bytes: `get(0x27)` starts `4B 80 27 00` and is 64 bytes; `set(0x18, [1])` starts `4B 01 18 01 01`; a 61-byte payload throws `IllegalArgumentException`.

**Transport:** claim only the HID interface (class 3, subclass 0, protocol 0), never the audio interface; prefer the interrupt endpoint pair whose endpoint number is 4 (address low nibble `0x4`), else the first pair. Use `UsbRequest` on the interrupt endpoints — queue the 64-byte buffer, wait up to 500 ms, three tries — not `bulkTransfer`, which is for Jiu's bulk endpoints. Release and close in `finally`. Do not run this while a phone call or USB audio route change is in progress.

4. A UI control that shows the current state and is gated on the device advertising the feature.

## 7. Decisions for the owner

1. **Do you have captures or firmware confirmation from Moondrop?** If yes, most of Tier 2 moves to Tier 1; if no, Tier 1 is intentionally visibility-only. A middle option is to ship read-only App-only probes in Tier 1; the plan does not, because the repo rule forbids sending uncaptured bytes by default.
2. **User-EQ `end` semantics:** is the second byte inclusive (0–4 = five bands) or a count? The 2026-10-07 reply (`00 01` + one band) disagrees with the inclusive reading. Re-probe with `0a05 00 04` before shipping any band UI.
3. **Dev options in release builds?** The plan assumes yes, off by default with a warning, because community testers need it. A debug-only console is safer but reaches nobody through F-Droid.
4. **Which USB family first?** SPV has the most models (14) but needs a HID transport; Comture/Jiu are simpler reads. The plan sequences SPV first for coverage.
5. **Tester matrix:** GAIA reads need any model advertising 13/22/26/31/33/34/35 (not the ST1); SPV needs a Dawn Pro 2/FreeDSP; Jiu a CHU2 DSP; Comture a Dawn; Synopsys an ECHO-B. Without at least one tester per track, Tier 2 code is written but unverified.
